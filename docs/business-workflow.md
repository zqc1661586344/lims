# 商务流程流转说明

> 本文档基于 `docs/process.md` 业务流程图与 `backend/internal/workflow/definition.go` 状态机整理，描述完整"商务流程"从开始到结束的执行顺序。

## 一、流程总览

流程从**任务新增（委托）**开始，最终到**项目归档**结束。共 **16 个节点**，每一步必须等当前节点"通过"（审核）才触发下一步。每个节点对应一个责任部门，并在相应步骤产出流程文档（D1–D15）。

```
业务室 → 技术室 → 质控室 → 现场室 → 现场室 → 样品室
     实验室 → 实验室 → 实验室 → 实验室
                   报告室 → 实验室 → 质控室 → 技术室
                   业务室 → 报告室（归档结束）
```

## 二、16 个节点逐步流转顺序

| 步骤 | 节点 | 责任部门 | 环节内容 / 产出文档 |
|---|---|---|---|
| 1 | 任务新增 / 委托 | 业务室 | 录入客户、项目、样品、检测项目，生成**委托任务单（D1）**，启动流程 |
| 2 | 合同评审 | 技术室 | 评审合同/协议，产出**检测合同/协议（D2）** |
| 3 | 质控任务 | 质控室 | 在检测任务中加质控方案，产出**委托检测方案（D3）** |
| 4 | 采样调度 | 现场室 | 安排采样团队、点位、设备 |
| 5 | 现场采样 | 现场室 | 现场采样，产出**现场采样记录及设备校准记录（D4）** |
| 6 | 样品接收 | 样品室 | 接收样品、编码登记，产出**样品接收记录（D5）** |
| 7 | 任务分配 | 实验室 | 把检测项目分配给实验员 |
| 8 | 数据录入 | 实验室 | 录入检测数据，产出**实验原始记录（D6）** |
| 9 | 数据复核 | 实验室 | 复核数据，**实验原始记录（D7）** |
| 10 | 数据审核 | 实验室 | 审核数据，**实验原始记录（D8）** |
| 11 | 报告编制 | 报告室 | 编制报告，产出**报告 + 实验原始记录（D9）** |
| 12 | 报告复核 | 实验室 | 复核报告，**报告 + 实验原始记录（D10）** |
| 13 | 报告审核 | 质控室 | 审核报告，**报告 + 实验原始记录（D11）** |
| 14 | 报告签发 | 技术室 | 签发盖章，产出**报告审核签发单（D15，汇聚 D9–D12）** + **报告 + 原始记录（D12）** |
| 15 | 报告发放 / 打印 | 业务室 | 打印发放给客户，产出**报告发放记录（D13）** |
| 16 | 项目归档 | 报告室 | 把 D1–D13 **所有文档**归档（D14），流程结束 |

## 三、部门泳道流转（简短版）

> 业务室(1) → 技术室(2) → **质控室(3)** → 现场室(4) → 现场室(5) → 样品室(6) → 实验室(7,8,9,10) → 报告室(11) → 实验室(12) → 质控室(13) → 技术室(14) → 业务室(15) → 报告室(16)

## 四、文档流转关系（D1–D15）

- **D1–D5**：委托任务单 → 检测合同 → 委托检测方案 → 现场采样记录及设备校准记录 → 样品接收记录
- **D6–D8**：实验原始记录（数据录入/复核/审核三环节）
- **D9–D12**：报告 + 实验原始记录（编制/复核/审核/签发四环节）
- **D15**：报告审核签发单（汇聚 D9–D12，在签发环节产出）
- **D13**：报告发放记录
- **D14**：以上所有文档（汇聚 D1–D13，在项目归档环节落入归档清单）

```
D9 ──┐
D10 ─┼──► D15（报告审核签发单）
D11 ─┤
D12 ─┘

D1 ──┐
D2 ──┤
... ─┼──► D14（以上所有文档）──► R2 项目归档
D13 ─┘
```

## 五、代码驱动机制

- 流程状态机位于 `backend/internal/workflow/definition.go`，每个节点定义 `NextNode`；节点被"通过"时，`engine.ApproveTask` 自动创建下一节点待办。
- 每个节点均支持**驳回**（退回上一节点），除：
  - 第 1 步 任务新增（流程起点，不能驳回）
  - 第 16 步 项目归档（终止节点）
- 待办展示于前端"待办任务"页的当前节点责任部门**部门待办** / **我的待办**中。

## 六、一句话总结

> **第 1 步任务新增（业务室）开始 → 依次经过合同评审（技术室）→ 质控（质控室）→ 采样（现场室）→ 样品接收（样品室）→ 数据三环节（实验室）→ 报告编制（报告室）→ 报告复核/审核/签发（实验室→质控室→技术室）→ 报告发放（业务室）→ 项目归档（报告室）结束。**
